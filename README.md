# Multimodal AI Surveillance & Behavior Analysis System

## Overview
An intelligent real-time surveillance system that combines YOLOv8 object detection, TorchReID person re-identification, and computer vision-based behavior analysis to monitor security events automatically.

## Features
- Real-time person detection using YOLOv8
- Multi-object tracking
- Person Re-Identification (TorchReID OSNet)
- Restricted Area Intrusion Detection
- Global Loitering Detection
- High-Risk Activity Detection
- Running Detection
- Fall Detection
- Entrance Monitoring
- Automatic snapshot capture
- CSV-based event logging
- Natural language incident search
- Streamlit dashboard
- Event filtering by date, time, event type and latest incidents

## Tech Stack
- Python
- YOLOv8 (Ultralytics)
- OpenCV
- TorchReID (OSNet)
- Pandas
- NumPy
- Streamlit
